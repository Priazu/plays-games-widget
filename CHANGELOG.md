# Changelog

## 1.1.2

- Added per-widget score-game selection with human-readable game names.
- Added support for using all published score-enabled games automatically.
- Improved infinite score feed: selected score games are shown first, then the wider Plays Games catalogue.
- Fixed automatic leaderboard switching between score-enabled games.
- Added a clear “No score for this game” state when browsing non-score games.
- Fixed Discover navigation from the score-games feed.
- Updated Doctrine DBAL parameter types for TYPO3 13 compatibility.
- Improved score catalogue and leaderboard integration.


## 1.1.1

- Improved TER and Composer metadata.
- Highlighted player scores, leaderboards and personal rankings.
- No functional changes.

## 1.1.0

- Added Scores & Progress experience for supported Plays Games titles.
- Added secure score capture and persistence for logged-in frontend users.
- Added configurable score-game selection.
- Added Leaderboard content element.
- Added automatic or fixed leaderboard game selection.
- Added podium display and current-player ranking.
- Added My Scores content element with per-game scores and rankings.
- Added support for multiple score metrics per game.
- Added score catalogue integration and validation.
- Improved score bridge and iframe message security.
- Improved frontend-user aware leaderboard rankings and player counts.
- Added localization support for score and leaderboard labels.

## 1.0.1

- Improved extension description and positioning.
- Highlighted the TikTok-style infinite swipe experience.
- Added information about visitor engagement and thousands of HTML5 games.
- Expanded documentation and Composer metadata.

## 1.0.0

Initial stable release.

- Added Plays Games Widget content element.
- Added configurable width and height.
- Added configurable corner radius.
- Added game category selection.
- Added automatic frontend rendering.
- Added TYPO3 13.4 LTS support.
