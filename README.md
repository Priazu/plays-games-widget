# Plays Games Widget for TYPO3

## Swipe. Discover. Play.

Plays Games Widget adds a TikTok-style infinite swipe feed of HTML5 games directly to your TYPO3 website.

Visitors can swipe through game previews and instantly play the games they like, creating a more interactive experience than a traditional game catalogue.

## Features

- Infinite vertical swipe game feed
- Thousands of HTML5 games
- Instant play
- Mobile-first responsive experience
- Game category filtering
- Configurable width, height and corner radius
- Multiple widgets supported
- No game hosting required

## Scores & Progress

Version 1.1 adds support for score-enabled Plays Games titles.

Supported features include:

- Secure score capture for logged-in TYPO3 frontend users
- Persistent player scores
- Multiple score metrics per game
- Central Plays Games score catalogue integration
- Score-game validation
- Configurable score-enabled games
- Secure iframe score bridge

## Leaderboard

The Plays Games Leaderboard content element can display rankings for score-enabled games.

Features include:

- Automatic tracking of the currently active score game
- Fixed-game leaderboard mode
- Configurable number of ranked players
- Podium display
- Current-player highlighting
- Current-player ranking even when outside the visible top positions

## My Scores

The Plays Games My Scores content element gives logged-in players a personal overview of:

- Games they have played
- Recorded scores and metrics
- Best values
- Ranking positions

## Configuration

Each Plays Games Widget content element can be configured independently:

- Width
- Height
- Corner radius
- Game category
- Experience mode

Score-enabled games are configured globally in the extension settings.

## Installation

Install the extension and add the desired Plays Games content element to a TYPO3 page.

Available content elements include:

- Plays Games Widget
- Plays Games Leaderboard
- Plays Games My Scores

No Plays Games-specific TypoScript configuration is required.

## Requirements

- TYPO3 13.4 LTS
- PHP 8.2 or later
- Internet connection
